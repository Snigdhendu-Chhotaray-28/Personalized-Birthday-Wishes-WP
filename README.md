🎉 Personalized Birthday Wish Generator

The Personalized Birthday Wish Generator is a modern, interactive, and fully responsive web project that allows users to create a custom birthday wish page using only two inputs — Sender Name and Receiver Name.
Once generated, the link opens a beautifully animated birthday page filled with interactive elements, floating balloons, confetti, candles, and warm wishes.

✨ Features
🎁 1. Custom Wish Link Creation

Users simply enter their name and the birthday person's name to instantly generate a personalized birthday wish link.

🎂 2. Dynamic Birthday Greeting Page

The generated page displays:
Receiver and sender names
Birthday messages
Animated cakes
Confetti effects
Floating balloons and decorations

🕯️ 3. Voice-Activated Candle Blowing

Using navigator.mediaDevices.getUserMedia() for microphone access:
The candle automatically goes out when the user blows air
Birthday music starts playing
Confetti pops on the screen

🎨 4. Beautiful UI/UX

Soft gradients
Floating elements
Smooth animations
Eye-pleasing colors
Tailwind CSS styling

📱 5. Fully Responsive Design

The website is optimized for:
Desktop
Tablet
Mobile devices

⚡ 6. Fast & Lightweight

Built using pure HTML, CSS, JavaScript, and Tailwind CSS — no heavy frameworks used.

🧰 Tech Stack

Frontend: HTML, CSS, JavaScript, Tailwind CSS
Audio/Interaction: navigator.mediaDevices.getUserMedia()
Animations: CSS animations, JavaScript DOM effects
Deployment: GitHub Pages / Netlify
